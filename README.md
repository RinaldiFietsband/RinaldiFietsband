# rinaldifietsband.win

I'm Ronald! This is the source of my hobby site: blog posts and resources.

Plain HTML and CSS, no build step, so it can be hosted anywhere
(GitHub Pages now, a self-hosted server later), with Cloudflare in front.

- `index.html`: home page
- `blog/`: one HTML file per post, list in `blog/index.html`
- `resources/`: files and guides, list in `resources/index.html`
- `style.css`: shared styling
- `CNAME`: custom domain for GitHub Pages
